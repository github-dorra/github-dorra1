## About

I'm an engineer in Telecommunications & IT who moved into **AI engineering** — I design systems that combine LLM reasoning with deterministic logic, because production AI needs both intelligence and control.

My latest project, **ZenifyTrip**, is a multi-agent travel recommendation engine (LangGraph) that reached a **96.8% success rate** with zero hallucinations in evaluation — built end-to-end, from data pipelines to production deployment. Before that, I worked across **Computer Vision** (brain tumor classification, traffic surveillance) and **NLP** (stress analysis from text).
